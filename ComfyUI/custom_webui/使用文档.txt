================================================================================
                    ComfyUI NodeStudio 使用文档
================================================================================

一、项目简介
--------------------------------------------------------------------------------

  NodeStudio 是 ComfyUI 的定制化 Web 前端，将复杂的节点工作流包装成简洁的
  参数面板。你不需要手动连线，只需在左侧填好参数，点击"开始生成"即可。

  支持的工作模式：
    - 文生图      (t2i)     输入文字描述，生成图片
    - 图生图      (i2i)     输入图片 + 文字，生成新图片
    - 图生视频    (i2v)     输入图片 + 文字，生成视频
    - 模特换脸    (face)    替换图片中的人物面部
    - 电商换衣    (clothes) 替换图片中人物的服装
    - 局部重绘    (inpaint) 只修改图片的指定区域


二、环境要求与启动
--------------------------------------------------------------------------------

  1. 先启动 ComfyUI
     ComfyUI 必须已经在运行，默认地址 http://127.0.0.1:8188
     启动命令（在 ComfyUI 目录下）：
       python main.py

  2. 再启动 NodeStudio
     在本项目目录下运行：
       python -m backend.run

     默认访问地址：http://127.0.0.1:8288

     如果 ComfyUI 在其他地址或端口，可通过环境变量指定：
       COMFY_BASE_URL=http://192.168.1.100:8188
       WEBUI_PORT=8288


三、界面概览
--------------------------------------------------------------------------------

  界面分为三大区域：

  ┌──────────┬──────────────────────┬────────────────────────┐
  │  侧栏    │    左侧参数面板      │    右侧输出视口        │
  │          │                      │                        │
  │ 工作流   │  提示词输入框        │   生成结果预览         │
  │ 模块     │  参数滑块/下拉框     │   放大/下载/转发按钮   │
  │          │  图片上传区          │                        │
  │ 主题     │  生成/批量生成按钮   │   进度条               │
  │ 切换     │                      │   执行状态信息         │
  │          │                      │                        │
  │ 资产库   │                      │   批量结果缩略图       │
  │ 提示词库 │                      │                        │
  │ 设置     │                      │                        │
  └──────────┴──────────────────────┴────────────────────────┘

  侧栏菜单：
    - 上半部分：工作流模块（文生图、图生图、图生视频、换脸、换衣、重绘）
    - 主题风格：暗夜/赛博/极简/蒸汽 四种主题
    - 下半部分：资产库、提示词库、设置


四、工作流绑定
--------------------------------------------------------------------------------

  每个工作模式默认绑定一个对应的工作流，也可以手动切换。

  操作步骤：
    1. 点击参数面板顶部的 "绑定工作流" 按钮
    2. 下拉菜单会列出所有可用工作流
    3. 选择一个即可切换，选择 "默认(自动选择)" 恢复默认

  注意：
    - 不同工作流暴露的参数不同，切换后参数面板会自动更新
    - 工作流文件位于 workflows/ 目录下，*.mapping.json 是配置文件
    - 点击刷新按钮 可以强制重新扫描工作流


五、添加新工作流
--------------------------------------------------------------------------------

  1. 在 ComfyUI 原生画布中设计并保存工作流
     保存路径通常在 ComfyUI/user/default/workflows/ 或 workflows/ 目录

  2. 启动 NodeStudio 后会 自动扫描并转换 工作流
     源目录包括：
       - ComfyUI/user/default/workflows/
       - ComfyUI/user/default/workflow/
       - custom_webui/workflows/

  3. 转换规则：
     - UUID Group Node（折叠节点）内的子图保持折叠状态
     - 只提取外部可编辑参数（提示词、采样参数、图片输入等）
     - 模型加载器等不需要切换的节点自动隐藏

  4. 刷新工作流：
     方式一：在前端点击刷新按钮（参数面板顶部）
     方式二：调用 API POST /api/workflows/refresh?force=1

  5. 查看已注册工作流：
     GET /api/debug/workflows          → 返回所有工作流 ID 列表
     GET /api/debug/workflows/{id}     → 返回指定工作流的详细结构


六、参数说明
--------------------------------------------------------------------------------

  【提示词】
    prompt / text  : 正向提示词，描述你想要的画面内容
                     例："一只猫在月光下跳舞，高质量，细节丰富"

    negative_prompt : 负向提示词，描述不想看到的内容
                     例："模糊，低质量，畸形的手指，水印"

  【采样参数】
    seed           : 随机种子，相同种子+相同参数 = 相同结果
                     点击锁图标可固定种子；点击骰子图标随机生成新的
    steps          : 采样步数，越大质量越高但速度越慢，通常 20-40
    cfg            : 提示词引导系数，越高越贴合提示词，通常 1-15
    sampler_name   : 采样器算法，如 euler、dpmpp_2m、ddim 等
    scheduler      : 调度器，如 normal、karras、exponential 等
    denoise        : 降噪强度，用于图生图，范围 0-1

  【尺寸设置】
    width / height : 输出图片/视频的宽高，单位像素

  【模型选择】
    ckpt_name      : 底模（Checkpoint 大模型）选择
    vae_name       : VAE 模型选择
    clip_name      : CLIP 模型选择
    lora_name      : LoRA 模型选择
    lora_weight    : LoRA 权重强度

  【视频参数】（仅在视频工作流中出现）
    frame_count / num_frames : 视频总帧数
    fps / frame_rate         : 帧率，每秒播放帧数
    duration                 : 视频时长（秒）
    motion_bucket_id         : 运动幅度
    augmentation_level       : 增强级别

  【控制参数】
    control_net_name : ControlNet 模型选择
    cn_strength      : ControlNet 控制强度
    start_percent    : 控制起始百分比
    end_percent      : 控制结束百分比


七、图片/视频上传
--------------------------------------------------------------------------------

  当工作流包含图片或视频输入节点时（如 LoadImage、LoadVideo），参数面板
  会自动显示上传区。

  操作方式：
    1. 点击上传区域选择文件
    2. 或直接拖拽图片/视频文件到上传区
    3. 已上传的图片会显示缩略图预览
    4. 点击缩略图右上角垃圾桶图标可移除

  支持的格式：PNG、JPG、MP4 等

  注意：
    - 图片会在点击"开始生成"时自动上传到 ComfyUI 的 input 目录
    - 上传采用 blake3 哈希去重，相同文件不会重复存储


八、批量生成
--------------------------------------------------------------------------------

  点击"批量生成"按钮可一次提交多个任务。每个任务的种子自动递增（如果锁定
  了种子）或随机生成。

  操作步骤：
    1. 点击批量生成按钮旁的齿轮图标，设置批量数量（1-50）
    2. 点击"批量生成"
    3. 生成结果下方会显示缩略图条，点击可在不同结果间切换

  注意：
    - 如果种子锁定，批量种子为 baseSeed + 0, +1, +2, ...
    - 如果种子随机，每个任务独立随机
    - 生成过程中可点击"中断生成"停止


九、结果操作
--------------------------------------------------------------------------------

  生成成功后，右侧视口显示结果。鼠标悬停在结果上会显示操作按钮：

    - 放大预览    : 在新标签页打开原图
    - 下载        : 下载结果到本地
    - 发送到...   : 将当前结果发送到其他工作流（如文生图的结果发送到图生视频）

  发送到其他工作流：
    1. 鼠标悬停在结果上
    2. 点击分享图标
    3. 选择目标工作流（图生图/图生视频/换脸/换衣/局部重绘）
    4. 界面自动跳转到目标工作流，图片自动填入上传区


十、资产库
--------------------------------------------------------------------------------

  资产库保存所有通过 NodeStudio 生成的图片和视频。

  功能：
    - 按日期分组展示
    - 支持预览、下载、删除
    - 分页浏览
    - 鼠标悬停显示操作按钮

  注意：
    - 生成结果会自动保存到资产库
    - 删除操作不可撤销
    - 资产存储在 ComfyUI 的输出目录中


十一、提示词库
--------------------------------------------------------------------------------

  提示词库用于收藏常用提示词，方便重复使用。

  收藏提示词：
    1. 在提示词输入框输入内容
    2. 点击输入框下方的星标按钮（★）
    3. 收藏成功后星标变为金色

  使用已收藏的提示词：
    1. 点击星标旁的书签按钮（提示词集锦）
    2. 在下拉列表中点击想要的提示词
    3. 提示词自动填入输入框

  取消收藏：
    - 再次点击星标按钮
    - 或在集锦列表中悬停提示词，点击出现的 X 按钮


十二、生成历史
--------------------------------------------------------------------------------

  点击顶部工具栏的"历史"按钮，打开历史记录面板。

  功能：
    - 查看所有生成记录（图片缩略图 + 提示词 + 时间）
    - 点击记录可直接预览该结果
    - 支持清空全部历史


十三、WebSocket 实时进度
--------------------------------------------------------------------------------

  NodeStudio 通过 WebSocket 连接 ComfyUI，实时显示生成进度。

  状态栏说明：
    - "节点运行中"（绿色）: WebSocket 已连接
    - "连接中..."（灰色）: 正在连接或已断开，会指数退避自动重连
    - 进度条显示当前采样步数
    - 下方终端显示各节点的独立进度


十四、API 接口参考
--------------------------------------------------------------------------------

  NodeStudio 后端暴露以下 API，可供外部调用：

  GET  /api/health                健康检查
  GET  /api/workflows             列出所有工作流
  POST /api/workflows/refresh     强制刷新并重新转换工作流
  POST /api/queue/batch           提交批量生成任务
  GET  /api/jobs/{prompt_id}      查询任务状态与结果
  GET  /api/queue                 查询 ComfyUI 队列状态
  POST /api/interrupt             中断当前生成
  GET  /api/assets                列出资产（支持分页）
  POST /api/assets/upload         上传文件到 ComfyUI input 目录
  DELETE /api/assets/{id}         删除资产
  GET  /api/assets/{id}/content   下载资产文件（支持 Range）
  GET  /api/ws                    WebSocket 代理
  GET  /api/ws-info               WebSocket 连接信息
  GET  /api/view                  流式代理 ComfyUI 文件查看
  GET  /api/debug/workflows       调试：列出工作流 ID
  GET  /api/debug/workflows/{id}  调试：查看工作流结构


十五、环境变量
--------------------------------------------------------------------------------

  变量名                默认值                    说明
  ─────────────────────────────────────────────────────────────
  COMFY_BASE_URL         http://127.0.0.1:8188     ComfyUI 服务地址
  WEBUI_HOST             127.0.0.1                 NodeStudio 监听地址
  WEBUI_PORT             8288                      NodeStudio 端口
  WORKFLOWS_DIR          custom_webui/workflows    工作流文件目录
  FRONTEND_DIR           custom_webui/frontend     前端静态文件目录
  WEBUI_REQUEST_TIMEOUT  120                       请求超时（秒）


十六、常见问题
--------------------------------------------------------------------------------

  Q: 点击生成后报错 "无法连接 ComfyUI 后端"
  A: 确认 ComfyUI 已启动，检查 COMFY_BASE_URL 地址是否正确

  Q: 生成报错 "unknown_workflow"
  A: 工作流 ID 未注册，检查 workflows/ 目录下是否有对应的 .mapping.json
     文件，或点击刷新按钮重新扫描

  Q: 生成报错 "ComfyUI 验证错误"
  A: 参数类型或值与工作流节点不匹配，错误详情会显示具体哪个节点哪个
     参数有问题。可以打开 ComfyUI 原生画布手动检查该节点

  Q: 切换工作流后参数面板为空或参数不对
  A: 新绑定的工作流与原来的字段不同，需要重新填写参数。点击刷新按钮
     确保工作流是最新的

  Q: 图片上传后不显示
  A: 检查文件格式是否为 PNG/JPG，文件大小是否超过 200MB 限制

  Q: 批量生成没有全部完成
  A: 某些任务可能因为 ComfyUI 队列拥堵或超时而未完成。检查状态栏
     信息，或直接查看 ComfyUI 原生界面的队列状态

  Q: WebSocket 一直显示"连接中..."
  A: 检查 ComfyUI 是否正常运行，检查防火墙是否阻止了 WebSocket 连接。
     系统会自动重试连接，最多 5 次
